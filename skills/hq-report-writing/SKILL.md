# 본부 총평 문장 규칙

## 독자와 목적
- 독자는 여러 센터를 관리하는 본부장. 리포트를 열자마자 이번 달 상황과 할 일을 안다
- 3~4문장: ① 이번 달 성과(월 절감액·탄소·목표 달성 센터 수) ② 눈에 띄는 변화나 센터 ③ 승인이 필요한 조치(없으면 "추가 조치 없음") ④ 센터별 설정 추천

## 숫자
- facts 에 있는 값만 쓴다. 합계·평균을 새로 계산하지 않는다
- 금액은 억·만 단위(`약 42.7억 원`, `3,100만 원`), 탄소 톤(`1,802톤`), 충진율 `%`, 변화 `%p`
- 센터 이름은 facts.statusCenters 표기 그대로(이미 짧게, 3곳 넘으면 "판교 외 5곳"으로 줄여 있음). 전 센터가 같은 판정이면 이름 없이 "전 센터"
- 월 값은 한 달 30일 기준이라는 리포트 규칙을 따른다(facts 값이 이미 그렇게 계산돼 있다)

## 판정·조치 말하기
- 판정 용어는 그대로: 양호 / 주의 / 효율 개선 필요 (목표: 포장 규제 대상 충진율 50%)
- 조치는 "ESG 우선 모드 적용", "규격 상한 15→20종 상향"처럼 facts 의 조치를 그대로 쓰고 "본부장 승인 필요"로 맺는다
- 원인을 추측하지 않는다(facts 에 없는 이유를 만들지 않음)

## 센터별 설정 추천 (④)
- 본부장이 센터마다 미세조정하는 3개: 월 절감액 기준(이만큼 아껴야 제안서 작성), 최소 충진율 개선 폭(낮출수록 제안이 많아짐), 목형비 회수 기간(신규 규격 초기비를 몇 개월 절감액으로 회수할지)
- facts.recommendations 의 "현재 → 추천" 값을 그대로 쓰고 "추천"으로 말한다(이미 바뀐 것처럼 쓰지 않음). 3곳 넘으면 앞 3곳 + "외 N곳(표 참고)"
- recommendations 가 비면 "센터별 설정은 현재 값 유지 추천"

## 금지
- facts 에 없는 숫자·센터명·원인
- 과장 표현, 재촉 표현
