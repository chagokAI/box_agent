# 차곡 에이전트

AI agents for box demand forecasting, packaging optimization, and operations reporting.

차곡 에이전트는 출고 이력과 재고를 바탕으로 다음 달 박스 주문을 제안하고, 센터별 운영 효율을 리포트로 정리합니다.
LangGraph와 MCP로 계산·검색·작성을 연결하며, 도구가 산출한 수치와 규정 근거를 담아 운영자가 검토할 수 있는 제안서를 만듭니다.

[실행 가이드](docs/guide.md) · [서비스 연동](INTEGRATION.md) · [배포 안내](docs/cicd.md)

## ✨ 주요 기능

- **다음 달을 준비하는 수요 예측** — 출고 이력, 현재 재고와 안전 재고를 바탕으로 주문 수량을 계산합니다.
- **더 잘 맞는 박스 제안** — 포장 효율을 분석하고 기성품·맞춤 규격의 비용과 도입 효과를 비교합니다.
- **근거를 함께 읽는 제안서** — 계산 도구의 수치와 RAG로 검색한 규정·반려 이력을 제안에 반영합니다.
- **운영자와 함께하는 의사결정** — 승인 전 대기하고 반려 의견으로 제안을 수정하며, 저장된 상태에서 작업을 이어갑니다.
- **센터를 아우르는 본부 리포트** — 센터별 효율을 비교하고 승인된 운영 기준 변경을 반영합니다.

## 🗂️ 프로젝트 구성

```text
box_agent/
├── agent_server.py    # 작업 API·실시간 진행·승인 처리
├── box_spec_agent.py  # 박스 주문 제안 그래프
├── hq_report_agent.py # 본부 리포트와 운영 기준 변경
├── mcp_servers/       # 업무 조회·계산·저장·규정 검색 도구
├── harness.py         # 실행 한도·재시도·검증·추적
├── prompts/           # 문장 작성과 규정·반려 해석 지시문
├── rules/             # 수량·규격·승인 판단 기준
├── knowledge/         # 규정과 반려 기록
├── tests/             # 계산·규정 검증과 에이전트 평가
└── docs/              # 실행·배포 안내
```
