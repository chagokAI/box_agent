# 포장 기울임 판정 정책 (POL-01)

> 목업 문서 — 시뮬레이션·RAG 시험용. 실제 사내 규정이 아니다. 시행 2026-09-01, 물류운영팀

## 1. 목적
상품이 박스에 똑바로(6방향 회전) 들어가지 않을 때, 한 평면 안에서 기울여 넣으면 들어가는지 판정하는 기준을 정한다.
기울임 판정은 포장 박스 배정과 박스 규격 제안(AI 제안서)에 같이 쓴다.

## 2. 판정 방법
- 상품 변 (p, q, r)의 모든 순서 × 박스 변 (a, b, c)의 모든 순서에 대해 r ≤ c 이고 rectFits(p, q, a, b)이면 들어간다고 본다.
- rectFits는 Carver 조건을 쓴다. p ≥ q, a ≥ b로 정렬한 뒤 (p ≤ a 이고 q ≤ b) 이거나,
  p > a, q ≤ b, p² + q² ≥ a² 이고 b ≥ (2pqa + (p² − q²)·√(p² + q² − a²)) / (p² + q²) 이면 들어간다.
- 한 평면 안에서만 기울이는 보수적 판정이다. 통과하면 실제로 들어간다.
- 충전율 계산은 기울임과 관계없이 부피비(상품 부피 / 박스 부피)로 한다.

## 3. 기울임 배정의 처리
- 기울임으로만 들어가는 배정은 충전율과 관계없이 검토(REVIEW) 대상으로 둔다. 자동 확정(MATCHED)하지 않는다.
- AI 제안서에는 기울임 배정 상품 수와 90일 출고 건수를 '확인 필요'에 적는다.
- 현장 포장 담당자가 기울여 넣기 어렵다고 판단한 상품(유리병, 액체, 파손 주의)은 기울임 배정에서 뺀다.

## 4. 정책 값
- 기울임 판정 사용 여부와 상품-박스 여유 간격(mm)은 물류운영팀이 정한다.
- 기본값: 박스 배정 화면은 끄기·여유 0mm, AI 제안서 계산은 켜기·여유 5mm.
- 크기 분류(size_class)는 표시용이라 이 판정과 무관하다.
